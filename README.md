Logica:
Tareas generales:
Decidir cómo se elige la palabra que el jugador debe adivinar.
Definir cómo se controla si una letra es correcta o incorrecta.
Mantener un registro de qué letras ya fueron adivinadas.
Revisar cuándo el jugador ha completado la palabra.
Pensar en las reglas del juego: cuántos intentos tiene el jugador, cuándo termina la partida.

Interfaz
Tareas generales:
Mostrar al jugador cómo va la palabra (letras adivinadas y espacios vacíos).
Indicar al jugador cuáles letras ya ha probado y cuáles están mal.
Pedir al jugador que ingrese una letra.
Mostrar mensajes finales cuando el jugador gana o pierde.
Asegurarse de que todo se vea claro y sea fácil de entender para el jugador.

Main
Tareas generales:
Organizar cómo se inicia, se juega y se termina una partida.
Coordinar la información entre la lógica del juego y la interfaz.
Controlar el flujo general: mostrar el estado, pedir letras, revisar resultados y actualizar los intentos.
Probar que todo funcione junto como un juego completo.
